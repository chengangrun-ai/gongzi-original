# 拼豆原创工坊100项优化实施计划

> **For agentic workers:** 使用 superpowers:subagent-driven-development 并行执行独立子任务，主代理负责集成与复核。

**Goal:** 在交接包v2的既有功能上，找到并落实100个可独立解释、可验证的优化，交付源码和新版可还原交接包。

**Architecture:** 保持原有模块接口和 numpy/Pillow/scipy 路线，按数据与方案、绘制与工艺、分析与核查、命令与交付四个独立领域改进。每个领域25项，最终合并清单并核查重复和证据。

**Tech Stack:** Python 3.12、numpy、Pillow、scipy、unittest、Git。

**Spec:** 用户最新请求“根据这里已经进行的所有工作、再继续优化、挑出可以优化的100个地方并进行优化”；输入为v2交接包全部源码，完整性差异见根目录source_integrity.json。

## Global Constraints

- 原始材料和已有演示不覆盖；修改发生在独立还原的v3目录。
- 不用文案拆分凑数；每项必须有不同的可观察问题或改进结果。
- 不改变原创性判定阈值，不把数值检测结果表述为法律结论。
- 全部内置风格、造型、构图和已有CLI继续可用。
- 各子任务只编辑自己拥有的模块、测试和记录；主代理统一Git提交。
- 本次直接优化，按用户流程跳过另行审批产品设计和技术设计，保留此执行计划供审阅。

## Review Focus

- 无效、空、边界、非有限数值输入必须明确报错，不能静默生成错误结果。
- 同种子重复构建的网格与参数必须一致，调用不能污染传入数据或全局默认值。
- 图片透明、旋转、损坏、重复和路径情况必须合理处理。
- 连通、色号、统计、网格往返、核查结论和导出目录必须相互一致。
- 重复构建、旧文件、私有参考图、压缩路径和交接包还原必须可验证。
