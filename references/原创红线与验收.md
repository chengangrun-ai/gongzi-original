# 原创红线与验收

## 一、为什么这套流程能叫"原创"

出发点：**风格本身不受著作权保护，受保护的是具体的画面表达。**
所以整套方法只从参考图里学"规律"，画面全部由代码从零画出来。

| 做 | 不做 |
|---|---|
| 统计配色比例、明暗分布、线宽、边缘密度、构图比例 | 描图、取样参考图像素 |
| 手写风格标签和规则 | 图生图、局部拼贴、滤镜套用 |
| 用样条/几何/程序化纹样从零画 | 把参考图缩到 52 格当图纸 |
| 用公共母题（骷髅、罗盘、莲花、青海波、曼陀罗） | 照搬某位作者对这些母题的具体排布 |
| 固定种子、留网格源文件、写原创性报告 | 用别人的作品"改一改"当原创 |

代码层面的保证：
- `pindou/` 下**没有任何函数读参考图**，唯一读图的是 `analyze.py`（只输出数字）
- 生成只用 `spec['seed']` 派生的随机数，同一份配置永远画出同一张图，可逐格复现
- 参考图目录只出现在 `--refs` 参数里，用于原创性核查，**不会进 zip**

## 二、绝不碰的东西

1. 动漫、影视、游戏角色（含二创形象）
2. 商标、品牌吉祥物、赛事标志
3. 名人肖像、真人照片的相貌特征
4. 他人签名、水印、店标
5. 参考图里的 IP：**只统计风格，不做同题材**

参考图里出现 IP 时，在风格简报里记一笔，并在 `subjects` 里避开同类题材。

## 三、原创性核查怎么算

```bash
python scripts/pindou.py check out/系列名 --refs <参考图目录>
```

1. 成品网格 → 墨量图（按色号亮度）→ 裁包围盒 → 拉伸 32×32
2. **NCC**：零均值单位向量余弦相似度（镜像也算，取大的）
3. **dHash**：9×8 差分哈希 64 位，取汉明距离最小值（含镜像）
4. 参考图先转成"照搬版"（直接缩到 52 格再量化），两边同尺度比

| 判定 | 阈值 |
|---|---|
| 与任何参考图 NCC | < 0.75 |
| 与任何参考图 dHash 距离 | ≥ 10 |
| 款与款之间 NCC | < 0.92 |

**超了就重画，不许调阈值。** 数值通过后还要人工复核：打开报告里 `nearest_ref` 最高的几款，
和对应参考图并排看，确认没有照搬它独特的构图或元素组合。

## 四、交付验收清单

- [ ] 总览图人工过了一遍：没有糊、断、飘、空、重复
- [ ] 每款都是一整片（四邻连通），熨完不掉零件
- [ ] 每款色数 ≤ 8，色号都在 MARD 卡里
- [ ] `原创性报告.md` 结论为"通过"，最像的几款已人工复核
- [ ] 参考图没有进 zip、没有进 git
- [ ] 网格源文件（`网格/*.txt`）齐全，能逐格复现
- [ ] 目录.csv / catalog.json 的数量、颗数、色数和网格对得上
- [ ] PNG 都带 Title/Author/Copyright/CreationTime 元数据
- [ ] 交付物：总览、色号图、原画、效果图、网格、目录、原创性报告、zip

## 五、存证建议

- 保留生成配置（风格包 JSON + seed），这是"创作过程"的证据
- 网格源文件是"作品原件"，进 git，带时间戳
- 卖得好的款到中国版权保护中心做美术作品登记
- 以上是工程防线，不构成法律意见；具体纠纷请咨询专业人士
