# 风格包规范

一个风格包 = 一份 JSON = 一套"某种画风怎么落成拼豆"的规则。**换风格只改 JSON，不改代码。**

位置：`styles/<id>.json`。`python scripts/pindou.py styles` 可列出全部。

## 最小可用例子

```json
{
  "id": "my_style",
  "name": "我的风格",
  "palette": {
    "white": "#FEFFFF",
    "light": "#B6B1BA",
    "mid": "#89858C",
    "dark": "#48464E",
    "line": "#000000",
    "accent": "#E7002F"
  },
  "line_width": 1.4,
  "fill_texture": "stipple",
  "subjects": ["cat", "moon", "flower"],
  "templates": ["badge", "frame", "fullsize"]
}
```

只要 `palette.line` 存在就能跑，其余字段都有默认值。

## 字段

### 颜色 `palette`
角色 → **理想颜色**（十六进制）。程序会在色卡里找最接近的真实色号（默认 MARD 72 色套装），
并把 ΔE 误差写进 `catalog.json`。

| 角色 | 作用 | 必需 |
|---|---|---|
| `line` | 描边、轮廓、深色细节 | **是** |
| `white` | 高光、眼白、留白、贴纸白边 | 建议 |
| `light` | 主体亮面 | 建议 |
| `mid` | 主体中间调 | 建议 |
| `dark` | 暗面、投影 | 建议 |
| `accent` | 点睛色（每款只用一处，面积小） | 可选 |
| `accent2` | 第二点缀（彩窗/波普用） | 可选 |
| `bg` | 满底铺色时的底色 | `bg=fill` 时必需 |

配色建议：**4–6 个角色**最稳。角色太多（>7）会糊，也太贵。

### 底色 `bg`
- `"paper"`（默认）：不铺底，外轮廓 1 格白豆托底，像贴纸。省豆、显干净。
- `"fill"`：整块铺满底色（要配 `bg_color`）。一整板豆，成品更"满"。

### 线 `line_width`
主轮廓线宽（格）。1.2–1.4 细线（纹身、线描），1.5–1.8 粗线（萌系、波普）。
**不要低于 1.2**：低于 1 格的线拼豆化时会断。

### 填充 `fill` / `detail` / `shade1` / `shade2` / `hi`
主体用什么角色填充、纹理细节用什么角色、暗面/更暗/高光分别用什么角色。
例：`"fill": "light", "detail": "line", "shade1": "mid", "shade2": "dark"`。

### 纹理 `fill_texture` / `face_texture` / `wing_texture` / `texture_pool`
14 种：`solid` `stipple` `hatch` `cross` `dots` `scales` `seigaiha` `waves` `checker` `halftone` `confetti` `contour` `weave` `gradient`

- `fill_texture`：主体默认纹理
- `face_texture`：脸/内部细节纹理（不给就跟随 `fill_texture`）
- `texture_pool`：给一个列表，**每款随机挑一种**，同一风格下也有变化（推荐）

选纹理的口诀：**线越细，纹理越要粗**。细线 + 密网点 = 糊。

### 画幅 `formats`
`S`（52×52，1 块板）/ `M`（78×78，4 块板）/ `V`（52×104，2 块板）的配比，加起来≈1。
竖图多的风格给 `V` 高一点，徽章类给 `S` 高一点。

### 构图 `templates`
16 个：`badge` `frame` `arch` `fullbleed` `medallion` `poster` `banner` `wreath` `radial` `window` `tile` `sticker` `card` `corner` `horizon` `scene`

`scene` 是风景/照片专用：天空 → 远山（两层）→ 主体 → 地面/水面 + 前景剪影，四层构图。

`build --templates a,b,c` 可临时覆盖。

### 题材 `subjects`
造型库里的名字（`python scripts/pindou.py motifs` 查）。每个造型自带中文名，作品名会自动取。

### 场景角色（只有 `scene` 构图用）
`sky_role`（天空，默认 light）、`hill_far`（远山，默认 mid）、`hill_near`（近山，默认 dark）、
`ground`（地面/水面，默认 shade1）、`cloud_n`（云的朵数）、`scene_rays`（太阳要不要光芒）。

### 点缀 `accent_policy` / `accent_rate`
`{"focus": 1, "max_area": 0.05}`：每款最多 1 处点缀，面积 ≤5%。
`accent_rate`：有多少比例的作品真的用点缀色（0.3–0.5 比较克制，0.8–0.9 更热闹）。

### 飞点 `splatter`
墨溅/飞点数量（0 = 不画）。**贴着主体画**，离远了会被当成碎块删掉。

### 难度系数 `difficulty`
```json
{"bead_div": 1100, "single_div": 220, "color_coef": 0.35, "board_coef": 0.25, "star_div": 1.35}
```
`score = 颗数/bead_div + 孤立单颗/single_div + max(0,色数−2)×color_coef + (板数−1)×board_coef`，
`星级 = clip(round(1 + score/star_div), 2, 5)`。
**换系列后要重新看星级分布**，让 2★/3★/4★/5★ 大致是 1:5:2:2，不要全挤在一档。

### 自动匹配用（可选）
`sat_target` `contrast_target` `edge_target` `ink_target`：`analyze` 靠这四个数给参考图找最像的风格包。

## 从参考图自动生成风格包

```bash
python scripts/pindou.py analyze <图目录> --save-style "风格名" --subjects cat,star,heart
```

会写出 `styles/<id>.json`（只含统计规律，不含任何像素）。之后按需手改：
通常要动的是 `subjects`（机器猜不出题材）、`templates`、`line_width`、`texture_pool`。

## 色卡

- `mard72`（默认）：72 色套装，便宜好买，配色要克制
- `mard291`：291 色全卡，细节多、色差小，但备豆成本高

色号以 MARD 体系为准（`H02` 白、`H03` 浅灰、`H04` 中灰、`H05` 深灰、`H07` 黑、`F05` 红……），
`assets/colorSystemMapping.json` 里带漫漫/COCO/盼盼/咪小窝的对照码，换色卡时查这个文件。
