# 风格简报模板

第 1 步用。**必须自己打开参考图看**，然后照着填。机器只会量数字，判断不了"这是什么画风"。

```json
{
  "风格名": "",
  "一句话描述": "",
  "主色": [],
  "线": {"颜色": "", "粗细": "细 1.2–1.4 / 中 1.5 / 粗 1.8"},
  "纹理感": "平涂 / 网点 / 排线 / 点刺 / 鳞片 / 渐变 / 编结 / 彩窗分区",
  "背景": "纸底留白（贴纸感）/ 满底铺色",
  "构图": "圆形徽章 / 几何框 / 拱框 / 满幅 / 竖幅垂坠 / 纹样铺贴",
  "题材": [],
  "点缀色": "",
  "要不要 IP": "有 IP 时写：只学风格，不做同题材"
}
```

## 填表要点

**主色**：写 3–6 个，标上角色。例：`["#FFE2CE 底", "#FFB7E7 主体", "#753832 线", "#FEFF8B 点缀"]`。
抄不准就用 `analyze` 的 `colors` 字段，它已经算好主色和占比了。

**线**：看图上的轮廓线占几颗豆。经验值：
- 细线（纹身、线描、和风）：1.2–1.4
- 中（大多数）：1.5
- 粗（萌系、波普、儿童）：1.7–1.9

**纹理感**：对照 14 种纹理挑一个最像的：

| 图上看到 | 用 |
|---|---|
| 纯色平涂、没有纹理 | `solid` |
| 点点、颗粒、点刺 | `stipple` |
| 斜排线、素描排线 | `hatch` / `cross` |
| 规则圆点、波点 | `dots` |
| 鱼鳞、龙鳞、羽毛层 | `scales` |
| 同心半圆、青海波 | `seigaiha` |
| 波浪、水纹 | `waves` |
| 方格、棋盘、像素 | `checker` |
| 印刷网点、波普 | `halftone` |
| 彩屑、纸屑 | `confetti` |
| 等高线、木刻、折面 | `contour` |
| 凯尔特编结 | `weave` |
| 水彩/渐变 | `gradient` |

**构图**：看参考图的主体怎么摆。
- 圆形/对称/徽章 → `badge` `medallion` `radial` `wreath`
- 有边框 → `frame` `arch` `window` `card`
- 满画面 → `fullbleed` `sticker` `poster` `horizon` `banner`
- 重复纹样 → `tile`
- 四角装饰 → `corner`

**题材**：把图里的东西逐个映射到造型库（`python scripts/pindou.py motifs`）。
映射不上就找近似造型，或者写一个新造型（`pindou/motifs.py`，20 行）。

**画幅**：参考图多为竖图就给 `V` 高权重，方形图多就给 `S`。

## 示例（复古日系少女漫）

```json
{
  "风格名": "复古日系少女漫",
  "一句话描述": "奶油底、粉紫主色、细线、网点阴影、圆形徽章构图",
  "主色": ["#FFE2CE 底", "#FFB7E7 粉主体", "#FFDBE9 浅粉", "#753832 深棕线", "#FEFF8B 点缀"],
  "线": {"颜色": "#753832", "粗细": "细 1.5"},
  "纹理感": "网点",
  "背景": "满底铺色",
  "构图": "圆形徽章为主，少量竖幅",
  "题材": ["cat_face", "star", "heart", "ghost", "rainbow"],
  "点缀色": "#FEFF8B",
  "要不要 IP": "无"
}
```
